# RC Admin UI plan (Phase 1)

## Goal

Native Android APK (Kotlin + Jetpack Compose + Material 3) for **RC Admin**, matching white/blue/black GATC references. Sample/local state only — no VPS, Firebase, or eMaap.

## Shell

- Compact width: modal left drawer  
- Medium/expanded: persistent sidebar  
- Nav: Dashboard, Verification, Customer, Product, Purchases, Settings→VCT/Vehicle/Laboratory, Profile  

## Delivered screens

Dashboard, Verification list/details, New OV, New RV, Customer, Product, Purchases, VCT, Vehicle, Laboratory, Profile.

## Next phases (out of scope)

Authenticated HTTPS APIs, signed PDF/image storage, eMaap worker, full multi-step OV/RV evidence capture.
